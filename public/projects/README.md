# Capturas de proyectos

Coloca aquí las imágenes de cada proyecto. La web las carga automáticamente con estos
nombres exactos:

| Archivo                 | Dónde se muestra                                        | Tamaño recomendado |
| ----------------------- | ------------------------------------------------------- | ------------------ |
| `sifa-web.png`          | SIFA — panel web (imagen principal)                     | 1600x900           |
| `sifa-movil.png`        | SIFA — app móvil SIFA GO (marco de teléfono)            | 600x1160           |
| `sifa-arquitectura.png` | SIFA — cuadro de arquitectura del ecosistema             | 1920x1080          |
| `ventas-greta.png`      | Sistema de Ventas Greta — imagen de la app de escritorio | 1600x900           |

Si un archivo no está (o se llama distinto), el sitio muestra automáticamente un recuadro
con las iniciales del proyecto y el nombre del archivo esperado, así que nunca queda roto.

Para verlas en local: `npm run dev` -> http://localhost:5173
